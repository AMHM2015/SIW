# SIW Admin Guide

This guide is for the person who updates the Sinsina Industrial Works (SIW) website using the admin page. No coding is needed.

For a print-ready copy, open [SIW-Admin-Guide.pdf](./SIW-Admin-Guide.pdf).

## Open the admin page

Open the SIW admin page using the address provided by your company. Enter your administrator password and choose **Open CMS**. If this is the first time the admin page has been set up, it may ask you to create the first password. Keep the password private.

If you cannot sign in, ask your website support person for help. Do not change website files or settings to solve a sign-in problem.

## Know what you are looking at

- **Left side:** choose a website page, open the Media library, or sign out.
- **Middle:** preview the selected page. Click text or an image here to select it.
- **Right side:** edit the selected item, manage repeatable items, and update page search details.
- **Top of the page:** **Save changes** publishes your edits. **Reset page** removes saved edits from the selected page.

The page list includes Home, About Us, Brochure, Career, Certifications, Clients, News, Products, Services, and Team.

> **Important:** Save your work before switching to another page. Unsaved changes can be lost when you change pages or close the admin page.

## Change text, an image, or a link

1. Choose the correct page on the left.
2. Click the words or image in the middle preview. You can also choose an item from **This page's fields** on the right.
3. Change the relevant text, image URL, link URL, or formatting on the right.
4. Choose **Apply to preview**. This changes the preview only; it does not publish the change.
5. Check the preview carefully, then choose **Save changes** at the top.
6. Wait for the **Changes saved** message before leaving the page.

For an image, upload it in **Media library**, choose **Copy URL**, then paste that URL into the selected item's **Image URL** field. Add or update the image's alt text when appropriate; this is a short description for people using screen readers.

For a link, check the full web address and button wording carefully before saving.

## Add or update a card or list item

Pages such as Products, Clients, News, Career, Team, Certifications, and Services can contain repeatable items.

1. Choose **+ Add** to create an item, or choose an existing item to edit it.
2. Enter its title, description, image details, and link details as needed.
3. Choose **Save item**. This updates the preview, but does not publish it yet.
4. Use the up/down arrows to change the order, or the delete button to remove an item.
5. Check the preview and choose **Save changes** at the top to publish.

Deleting an item takes effect on the website after **Save changes**. Check the page carefully before publishing.

## Manage leadership cards

The **About Us** page has a **Leadership cards** list in the right-hand panel. It starts with the seven current SIW leaders. To edit one, select its name in the list or click its card in the middle preview.

- **Add a card:** choose **+ Add**, enter the person's name, and choose **Save item**.
- **Add or change a photo:** while editing a card, choose **Choose image**. Upload a new image in the media library if needed, then select **Use image** on the photo you want. Add a useful alt description for accessibility.
- **Finish editing:** choose **Save item** to update the preview, then **Save changes** at the top to publish.
- **Reorder cards:** use the up and down arrows beside a name.
- **Remove a card:** choose its delete button. Keep at least one leadership card.

Leadership cards show a person's name and photo; they do not have a role or description field.

## Update page title and description

The **SEO** fields are on the right side near the bottom:

- **Browser title:** the title shown in a browser tab and often in search results.
- **Meta description:** a short summary that may appear in search results.

Enter plain, accurate wording and choose **Save changes** at the top.

## Use the Media library

1. Choose **Media library** on the left.
2. Select an image or video file and choose **Upload**.
3. When it appears in the library, choose **Copy URL**.
4. Close the library and select the image or item you want to update. For a leadership card, choose **Use image** directly in the library; for other items, paste the URL into the **Image URL** field and choose **Apply to preview**.
5. Choose **Save item** when editing a card, then choose **Save changes** at the top to publish.

The library accepts JPG, PNG, GIF, WebP, and AVIF images, and MP4, WebM, and MOV videos. The file limit is 100 MB.

**Deleting a media file is immediate and cannot be undone.** Do not delete a file if it may be used on a website page.

## Reset a page

**Reset page** removes the saved CMS edits for the currently selected page and returns it to its original website content. This includes that page's saved text, item changes, and SEO details. It is not a way to undo just the last change.

Use it only if you intend to remove all saved edits from that page. Confirm the page name first. If you are unsure, do not reset; ask your website support person.

## If something does not look right

- **Your change is not visible on the website:** make sure you chose **Apply to preview**, then **Save changes**, and saw **Changes saved**.
- **You are about to leave with changes:** save first; changing pages can discard unsaved work.
- **An upload or save shows an error:** note the message and ask your website support person. Avoid repeated retries if you are unsure whether an upload succeeded.
- **You see a different screen with a “Preview Data” button or a message that backend saving can be connected later:** that is a demonstration form, not the publishing editor. Return to the SIW CMS admin page or contact support.

When finished, choose **Sign out** on the left.
